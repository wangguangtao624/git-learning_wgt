# Git 与 GitHub 学习笔记

面向零基础学习者：先理解，再动手，每次只掌握一小步。

## 学习路线

1. Git、GitHub、仓库和版本：建立整体概念。
2. 查看与记录：status、add、commit、log、diff。
3. 连接 GitHub：clone、remote、fetch、pull、push。
4. 分支和合并：branch、switch、merge，理解冲突。
5. 协作：Issue、Pull Request、代码审查。
6. 安全撤销与排错：restore、revert、reset 的区别。
7. 进阶：忽略文件、标签、暂存工作、rebase 和常见工作流。

## 第一课：Git 与 GitHub

Git 是安装在电脑上的版本管理工具，能记录文件的历史。GitHub 是托管 Git 仓库并提供协作功能的网站。仓库可以理解为项目文件和版本历史的集合。

```mermaid
flowchart LR
    A["电脑里的文件"] -->|git add| B["暂存区：准备保存的内容"]
    B -->|git commit| C["本地仓库：历史记录"]
    C -->|git push| D["GitHub：远程仓库"]
    D -->|git pull| C
```

- `git status`：查看当前状态，不会修改文件。
- `git add 文件名`：选择要放进下一次记录的内容。
- `git commit -m "说明"`：在本地创建一条版本记录。
- `git log --oneline`：简洁地查看提交历史。
- `git push`：将本地提交上传到远程仓库。

**关键区别**：保存文件、提交到本地 Git、推送到 GitHub 是三个不同的动作。

## 练习

先在终端进入仓库目录，然后执行：

```powershell
git --version
git status
```

观察 Git 版本、当前分支和文件状态。练习前先看懂输出，不要急于执行会覆盖或删除内容的命令。
